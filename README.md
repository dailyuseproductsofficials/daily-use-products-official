# বাংলা পার্সোনাল ড্যাশবোর্ড — নতুন সেটআপ

আগের ড্যাশবোর্ডের নকশা ও `logo.jpg` বজায় রেখে নতুন GitHub Pages + Firebase প্রজেক্টে চালু করার starter package।

**শুরু করার আগে:** `SETUP-GUIDE-BN.txt` সম্পূর্ণ পড়ুন। `index.html` ও `admin.html`-এর Firebase config placeholder নতুন Firebase Web App config দিয়ে পূরণ করতে হবে এবং `firestore.rules`-এ আপনার admin UID বসাতে হবে।

- `index.html` — public dashboard
- `admin.html` — admin interface
- `layout-manager.html` — card layout manager
- `firestore.rules` — Firestore security rules template
- `logo.jpg` — existing logo

এটি প্রস্তুত starter package; Firebase ও GitHub Pages-এ নিজের অ্যাকাউন্টে setup/publish না করা পর্যন্ত live site সম্পূর্ণ সক্রিয় হবে না।
